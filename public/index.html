One Horizon webhook receiver

This Vercel project is ready to receive One Horizon app webhooks.

Use /webhook as the endpoint in One Horizon.

If /webhook returns 401, the request is missing the webhook key or the key does not match.

  1. Set ONE_WEBHOOK_KEY in Vercel.
  2. Use the same key in your One Horizon webhook settings.
  3. Send requests with the x-one-webhook-key header.
