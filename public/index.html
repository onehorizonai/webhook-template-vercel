One Horizon webhook receiver

This Vercel project is ready for One Horizon app webhooks.

Use /webhook as the endpoint URL in One Horizon.

A browser visit to /webhook can return 401. Send the webhook key header instead.

  1. Set ONE_WEBHOOK_KEY in Vercel.
  2. Use the same key in your One Horizon webhook settings.
  3. Send requests with the x-one-webhook-key header.
